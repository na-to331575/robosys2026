# robosys2026

![test](https://github.com/na-to331575/robosys2026/actions/workflows/test.yml/badge.svg)


標準入力から受け取ったデータを処理して標準出力に出力するコマンド群です。筋トレの1RM（最大挙上重量）を計算する `rmcalc` コマンドと、数値の合計を求める `plus` コマンドを収録しています



##インストール方法
git clone [https://github.com/na-to331575/robosys2026.git](https://github.com/na-to331575/robosys2026.git)
cd robosys2026
chmod +x rmcalc plus


###コマンド一覧

##rmcalc コマンド
- 筋トレの挙上重量（kg）と回数（reps）を標準入力から受け取り、推定最大挙上重量（1RM）を計算して標準出力に出力するコマンドです。
- 計算式　(O'Conner法)
 - 1回(１rep)の場合：入力重量をそのまま出力
 - 2回以上の場合:1RM = 重量 × (1 + 回数/40)

#使い方・実行例
標準入力から 重量 回数 を半角スペース区切りで渡します。複数行（複数セット）の一括計算にも対応しています。

- 1セット分を計算する場合
$ echo "60 10" | ./rmcalc
75.0

- 複数セット分をまとめて計算する場合
$ printf "60 10\n80 5\n" | ./rmcalc
75.0
90.0

#エラーの仕様
以下の不正な入力が渡された場合は標準エラー出力にメッセージを表示し、終了ステータス 1 で異常終了します。
- 数値以外の文字列が含まれる場合
- 一行あたりの項目数が2つ出ない場合
- 重量または回数が0以下の場合
- 入力が空の場合

##plusコマンド
- 標準入力から1行ずつ読み込んだ数値（整数・小数）をすべて足し合わせ、合計値を標準出力に出力する。入力がすべて整数の場合は整数で、小数が含まれる場合は小数で出力する。


#使い方・実行例
- 1から5までの整数を足す場合
$ seq 5 | ./plus
15

- 小数点を含む数値を足す場合
$printf "1.5\n2.5\3\n" | ./plus

7.0

#エラーの仕様
以下の不正な入力が渡された場合、ValueError を送出して終了ステータス 1 で異常終了する。
- 数値に変換できない文字列(全角文字や記号など)が含まれる場合
- 空行や何も入力されなかった場合
